# Punto de Venta Express

Producto móvil independiente para taquerías, puestos de comida y negocios pequeños.

## Primera etapa

- Interfaz adaptable a teléfono y tableta.
- Pedidos para mesa, mostrador y para llevar.
- Productos, cantidades, notas y cuenta abierta.
- Envío de comanda con folio.
- Base instalable como PWA.

## Probar localmente

Abrir una terminal en esta carpeta y ejecutar:

```powershell
python -m http.server 8080
```

Después visitar `http://localhost:8080`.

Esta carpeta no utiliza la base de datos, clientes ni imágenes privadas de LaEsquinaManager.
